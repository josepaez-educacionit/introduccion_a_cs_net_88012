static decimal CalcularPrecioConDescuento(decimal precioLista, decimal porcentajeDescuento)
{
    decimal montoDescuento = precioLista * porcentajeDescuento / 100;
    return precioLista - montoDescuento;
}

Parte 5 · Paso por referencia
El mismo problema, dos formas de pasar

      

        
        
      

      

        
Por valor
          
AplicarInteres(saldoCuenta, 5m);

          
Después de invocar:
El original no cambió.

        
Por referencia
          
AplicarInteres(ref saldoCuenta, 5m);

          
Después de invocar:
El original se modificó.

Criterio
