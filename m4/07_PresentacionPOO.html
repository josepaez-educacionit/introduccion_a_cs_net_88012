Parte 4 · Properties y validación
El field guarda el dato; la property lo controla

      

        

          Field
          
Solo almacena. No puede validar.

          
public decimal Saldo;   // sin control

        

        

          Property
          
Controla cómo se lee y se escribe.

          
public decimal Saldo { get; private set; }
// auto-implementada: el compilador crea el field

        

      

      
Regla práctica: fields privados (_saldo) y properties públicas (Saldo).

    Parte 7 · Composición de objetos
    Un objeto puede estar formado por otros objetos
    
      
    Relación "tiene un": un Cliente tiene una Direccion y varias Cuenta.
    
      
    
        
    
          
    
            
    Cliente
    
            
    Nombre = "Elena"
    
          
    
          
    
            
    Direccion
    Calle = "Av. Siempre Viva 742"Ciudad = "Springfield"
    
          
    
          
    
          
    
            
            
          
    
          
    
        
    
        
    class Cliente
{
    public string Nombre { get; private set; }
    public Direccion Domicilio { get; private set; }
    private List<Cuenta> _cuentas = new List<Cuenta>();

    public Cuenta AbrirCuenta(decimal saldoInicial)
    {
        Cuenta nueva = new Cuenta(Nombre, saldoInicial);
        _cuentas.Add(nueva);
        return nueva;
    }

    public decimal SaldoTotal()
    {
        decimal total = 0m;
        foreach (Cuenta c in _cuentas)
            total += c.Saldo;
        return total;
    }
}
